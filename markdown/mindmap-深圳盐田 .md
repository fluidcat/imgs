# 深圳盐田 

## 海滨栈道

- 全程线路：大梅沙驿站-背仔角灯塔
- ①驿站->大梅沙：风景好，人多
- ②大梅沙：沙滩+街道路❌
- ③大梅沙东->小梅沙：万科天琴湾，人少|风景好
  - 车停到大梅沙
  - 大梅沙地铁站
- ④小梅沙：施工路段❌
- ⑤小梅沙东->背仔角灯塔：人少|风景好
  - 导航小梅沙公交站，就地找停车
  - 小梅沙地铁站
